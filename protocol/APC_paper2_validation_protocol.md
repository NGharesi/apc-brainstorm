# Paper 2, analysis 2: out-of-sample validation of the spectral-peak pipeline and a final test of burst and event timing

Written 2026-10-24, after the component ablation (protocol/APC_paper2_component_ablation_protocol.md, outputs in revision_checks/paper2_ablation) and before any signal used here exists. Committed and pushed on branch `paper2` before anything is generated or run. Changes are appended as dated amendments.

## 1. Questions

The ablation favoured "SP-raw fP + one-dimensional amplitude scan" (F3 x A_SCAN). That pipeline emerged from the ablation, so it is tested here on fresh signals.

- **Q1 (out-of-sample):** does F3 x A_SCAN recover the (fP, fA) pair more often than APC v1.0 and the two-dimensional A2' scan?
- **Q2 (event timing for fA):** does the event-based amplitude rule (APC-event-carrier, `src/apc_event_carrier.m`, unchanged) choose fA better than the continuous-envelope scan?
- **Q3 (burst timing for fP; the never-run premise test P1 of protocol/APC_protocol_amendment_2026-10-20.md):** when bursts are locked to a rhythm that is not the dominant spectral peak, does APC's burst-triggered fP identify the coupled rhythm more often than the spectral peak?

## 2. Methods (all on identical signals)

### fA rules, given fP
- **A_SCAN:** one-dimensional MVL-Ozkurt scan at the fixed fP (`scan_fa_given_fp.m` from the ablation; phase band fP +/- 1.5 Hz; SOS-guarded filters).
- **A_EVENT:** `apc_event_carrier.m` exactly as frozen (protocol/APC_event_carrier_validation_protocol.md): amplitude half-width 6 Hz, phase half-width 1.5 Hz, event threshold median + 0.75 SD, prominence 0.25 SD, minimum separation 20 ms. Amplitude candidates = the dataset's amplitude grid (table below). fP is supplied by passing a copy of the APC output structure whose fP field is replaced by the source's fP (no other field changed), as `run_apc_premise_two_rhythm_benchmark.m` already does for the spectral-peak input.
- **A_APC:** APC Steps 3-4 at the fixed fP (`apc_fa_given_fp.m` from the ablation).

### Pipelines and references

- References: the A2' two-dimensional scan; APC v1.0 and v3.0 end-to-end (identical to F1 x A_APC and F2 x A_APC; their agreement is reported as a check).
- Coupling for every method = normalized MVL at its selected pair (ablation rule).

## 4. Endpoints (fixed here)

Joint recovery = |fP error| <= 1 Hz and |fA error| <= 8 Hz; strict = |fP error| <= 0.5 Hz. Invalid outputs count as failures. Exact two-sided McNemar tests; Wilson 95% CIs.

### P-A (primary, Q1)
- Joint recovery, F3 x A_SCAN vs APC v1.0 and F3 x A_SCAN vs A2', in V1 and V2. Four contrasts, Holm corrected.
- **Decision:** the pipeline is **validated** if it is significantly better than both references in both V1 and V2. **Partially validated** if better in some contrasts and worse in none. **Not validated** otherwise.

### P-B (primary, Q2)
- Joint recovery, A_EVENT vs A_SCAN at F3 and at F2, in V1 and V2. Four contrasts, Holm corrected.
- **Interpretation:**
  - A_EVENT significantly better in at least two contrasts and worse in none: event timing helps fA;
  - A_SCAN significantly better in at least two contrasts: it does not;
  - otherwise: no difference shown.

### P-C (primary, Q3)
- Recovery of the coupled rhythm's fP (within 1 Hz) in the non-dominant cells (A_keep100, A_keep040, B_keep100, B_keep040 pooled; n = 400):
  - F2 vs F3 (main test);
  - F1 vs F3 (Holm over the two).
- Also report per cell, and the rate at which each source returns the uncoupled (dominant) rhythm.
- **Decision:**
  - burst timing identifies the coupled rhythm beyond the spectral peak if F2 or F1 is significantly better than F3 (Holm);
  - otherwise the paper states that, in these simulations, the burst-based fP was not shown to improve on the spectral peak.

### Secondary
1. Strict recovery and errors for all methods in V1-V4.
2. **Specificity:**
   - false joint recovery in paired timing nulls (V1, V2) and in N_uncoupled (V3);
   - AUC of coupling, coupled vs paired null, with pair-bootstrap CIs (10,000, seed 20261114).
3. **Calibrated coupling test for F3 x A_SCAN** (the full A2' grid is too costly with surrogates and is not tested):
   - statistic = maximum normalized MVL over the amplitude grid at F3's fP;
   - null = 200 circular shifts of all amplitude envelopes relative to the phase signal, with shifts uniform in [0.25T, 0.75T] (seed 20261115);
   - p = (1 + number of surrogates >= observed) / 201;
   - report the false-positive rate at alpha = 0.05 in the timing nulls and N_uncoupled, with Wilson CIs, and the power in the coupled trials.
4. V4 joint recovery.

## Amendment 1 (2026-10-24): how fP is passed to A_EVENT

Written after the ablation archive was pushed (f66acb5) and before any gate was run, any V-suite was generated or any method was computed. Raised by the executor: unchanged `src/apc_event_carrier.m` reads both `status_code` and fP from its input and returns at once if the status is nonzero, so "a copy of an APC output with only fP replaced" makes A_EVENT depend on which APC output is copied and on whether APC Steps 3-4 succeeded.

Replacement for the A_EVENT input rule in section 2:

- A_EVENT receives the minimal input structure that `apc_event_carrier.m` already accepts (the form used for the spectral-peak input in `run_apc_premise_two_rhythm_benchmark.m`): `struct('status_code', s, 'fp_hz', fP)`.
- `fP` is the fP source's estimate. `s = 0` if the source returned a finite fP; otherwise `s` is the source's own status code (for example 3 for F2 or F3 with no admissible candidate) and A_EVENT is invalid for that trial.
- So A_EVENT runs whenever its fP source succeeds, for F1, F2 and F3 alike. This matches A_SCAN and A_APC, which run at any finite fP, and ablation Amendment 2, under which F1 and F2 keep their Step-2 fP even if later APC steps fail. APC end-to-end status is not inherited.
- `apc_event_carrier.m` is unchanged.
- The G-event gate becomes: on the canonical input, the call with the minimal structure carrying APC v1.0's fP equals (to 1e-12) the call with APC v1.0's original output, and two identical calls agree.
- Descriptive addition: for F1 and F2, report the number of trials or bouts in which the Step-2 fP is finite but APC end-to-end status is nonzero (the only trials in which F1 x A_EVENT can differ from the original APC-event-carrier, which inherited APC status).
